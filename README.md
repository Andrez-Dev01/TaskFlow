# TaskFlow

A full-stack task management application built with **Go, JavaScript, PostgreSQL, and REST APIs**.

TaskFlow is a portfolio software engineering project focused on building a complete application from the ground up while practicing backend development, API design, relational databases, frontend development, testing, version control, and cloud deployment.

The project is intentionally being developed incrementally. Each milestone introduces new functionality only after the previous layer of the application is working and understood.

---

## Project Status

> **Status:** In Development

TaskFlow is currently being built from the ground up. Features and architecture may evolve as development progresses.

### Current Phase

**Milestone 0 — Project Foundation**

The initial focus is establishing the repository, Go project structure, development environment, and application foundation before implementing product features.

---

## Project Goals

TaskFlow is designed to provide hands-on experience building and maintaining a full-stack application.

The project focuses on:

- Backend development with Go
- HTTP and REST API design
- Relational database design
- PostgreSQL integration
- CRUD operations
- JSON request and response handling
- Input validation
- Error handling
- Frontend/backend communication
- Searching and filtering data
- Automated testing
- Git and GitHub workflows
- Application configuration
- Deployment
- Cloud fundamentals with AWS

The goal is not to add unnecessary technologies. New tools should only be introduced when they solve a real project requirement.

---

## Core Features

TaskFlow will allow users to manage tasks through a web interface backed by a REST API and PostgreSQL database.

### Task Management

Users will be able to:

- Create tasks
- View tasks
- Edit tasks
- Delete tasks
- Assign task status
- Assign task priority

### Organization

Tasks will support:

- Status tracking
- Priority levels
- Filtering
- Searching

### Persistence

Task information will be stored in PostgreSQL so that application data remains available between application sessions.

### REST API

The Go backend will expose REST endpoints used by the frontend to perform task operations.
